## 🏆 Featured Projects

### 🤖 [TaskAgent - Autonomous AI Planning Agent](https://github.com/manivuppala124/TaskAgent)
**Tech Stack:** FastAPI, Gemini 1.5 Flash, LangGraph, Streamlit, LangChain
- Designed an autonomous planner that transforms natural language goals into structured execution plans
- Utilized LangGraph for dynamic task decomposition and intelligent execution flow
- Built modular architecture enabling LLM-driven planning and real-time task tracking

### 📚 [EduBot Pro - AI Document Assistant with RAG](https://github.com/manivuppala124/EduBot)
**Tech Stack:** Python, FastAPI, LangChain, Gemini 1.5 Flash, FAISS, Streamlit
- Built a Retrieval-Augmented Generation (RAG) based AI assistant for PDF document queries
- Engineered full pipeline: PDF ingestion, chunking, embeddings, vector search, and answer generation
- Designed modern Streamlit frontend for real-time document uploads and interactive Q&A

### 🎯 [AI-PathGen - Smart Ed-Tech Platform](https://github.com/manivuppala124/AI-PathGen)
**Tech Stack:** MERN Stack, LangChain, Cohere API
- Developed adaptive learning platform generating quizzes and summaries using GenAI
- Achieved **90%+ accuracy** in content relevance using LangChain and Cohere
- Enabled content customization for personalized learning experiences

### 📰 [News Headline Classifier & Summarizer](https://github.com/manivuppala124/News-Headline-Generator)
**Tech Stack:** Python, Flask, Hugging Face Transformers, Scikit-learn
- Built classification system using logistic regression on TF-IDF vectors
- Integrated Hugging Face summarization pipeline for real-time insights
- Achieved **85% accuracy**, scalable for news agencies and aggregators
